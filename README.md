# Vleewaren Vermeir

Nuxt 4 project met Tailwind CSS v4 en Naive UI.

## Setup

Installeer de dependencies:

```bash
npm install
```

## Development

Start de development server op `http://localhost:3000`:

```bash
npm run dev
```

## Productie

Build voor productie:

```bash
npm run build
npm run preview
```
